# Diagramas para exposición

Estos SVG explican la implementación de las semanas 4 y 5. Se pueden abrir en
un navegador, insertar en diapositivas o convertir a PNG sin perder calidad.

| Archivo | Uso sugerido |
|---|---|
| `01-ciclo-controlador.svg` | Explicar qué pasa en cada tick de simulación. |
| `02-estados-seguros.svg` | Explicar la secuencia de operación, mantenimiento y fallo. |
| `03-cadena-evidencia.svg` | Explicar cómo se valida el resultado y qué evidencia produce cada módulo. |

Los diagramas muestran la arquitectura implementada con el doble determinista.
La conexión real con CoppeliaSim, las POs de M1/M2 y las corridas finales
siguen pendientes; no deben presentarse como resultados ya medidos.
