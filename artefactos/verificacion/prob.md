# A17 — Exploración ProB

La configuración de `modelo/prob/configuracion.json` fija la instancia finita
de una zona y dos operarios y los datos que se deben guardar. No hay una
ejecución ProB en este repositorio porque M2 aún es un borrador legible, no una
máquina Rodin nativa. Por ello no se informan estados, transiciones, cobertura
ni ausencia de deadlocks.

Cuando exista M2 nativo, guardar en `artefactos/verificacion/prob/` el comando
o configuración, versión de ProB, límites, log y contraejemplos reproducibles.
